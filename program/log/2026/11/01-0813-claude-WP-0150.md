## Decisions, risks or questions raised
- **Held calls pause only where a step can re-run:** sequential pipeline steps and graph agent nodes. A consensus candidate or a peer-review round re-running would change the other steps' inputs, so there the agent is told the call needs approval, as before; the approval still lets the same call run once later.
- **A paused step re-runs from its start** with the approved call allowed once. The model may choose differently on the re-run; then the grant stays unused and the new call is checked as usual.
- **Voice approval never executes the plan:** it returns the plan to the speaker to confirm, so an Administrator cannot run someone else's command.
