## Lessons recorded in the WP Progress log

- An approval node's row is never marked finished, so stage duration
  must be entered → left, not "all nodes finished".
- `user_service::create` eagerly assigns the Standard User role; a
  negative access test must remove it first.
- `laneAnchorLabel` already existed (record-shaped); the duplicate
  function declaration broke the whole demo page at load and
  `node --check` did not catch it — the browser load is the real check.
- `CI=true` disables the Playwright webServer, so server-backed specs
  fail with ECONNREFUSED on :3000; run them without CI after building
  the server, with cargo on PATH.
