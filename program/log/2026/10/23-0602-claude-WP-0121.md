## Decisions, risks or questions raised
- **The tools-off final answer keeps the tool definitions.** A history holding tool calls is only valid next to them. Each provider is told in its own format not to call a tool. If the model still asks for one, nothing runs and the answer is empty.
- **The final-answer instruction is added to the system prompt, not the conversation.** That way no message the person did not write appears in their chat history.
- **The per-run token limit counts tokens in one agent run.** In an execution graph that is one agent step, which matches REQ-LOOP-009's per-step wording.
- **The time limit is per model call (REQ-LOOP-010).** It covers that tier's retries together. Only one timeout moves to the next tier; a second ends the run.
- **WP-0140 is blocked on tracing.** Its AC-1 requires ADR-0008 tracing, and the span store is WP-0111 (proposed). Recorded on WP-0140.
