## Decisions, risks or questions raised
- **Spans use a thread-local stack**, the same choice `principals` made: a run and its delegations execute on one thread, and nothing in core awaits concurrently. If that ever changes, the stack must move into an explicit context.
- **Model calls record no cost.** Prices arrive with the model catalog (WP-0146).
- **Bodies store only the newest message of each round.** A span's input body is the newest message sent that round (the user's turn or the tool results), not the whole history, so a trace does not repeat the conversation in every round.
- **The rate-limit window lives in the database**, so limits hold across a server restart, and calls older than 24 hours are pruned on each counted call.
