## Decisions, risks or questions raised
- **A paused connection is enforced.** A pause that did nothing would have been another setting that does nothing, which is what this work package removes.
  - `paused` is a new status. `disabled`, the default for new connections, keeps working as before, so no existing setup changes.
  - Admins see `paused` as a badge. The admin screen does not yet offer a pause button; that is a possible follow-up.
- **No secret leaks from listings.** `config_json` is left out of connection listings because default headers can hold tokens.
