## Decisions, risks or questions raised
- **RAID I-32, found and fixed.** Business Rules that block a save were never applied to REST, MCP or CSV-import writes. AC-6 needed them for bulk writes, so they now apply to every API-shaped write.
  - This is a behaviour change: an integration that used to create records a rule forbids will now get 400.
  - It is announced in the Releases entry.
- **Export memory.** The response is streamed in 500-record chunks, but the record list is still loaded whole from the entity services, as the existing records endpoint does. Streaming straight from a database cursor would need per-object paging in every service; it is noted in the Progress log as a possible follow-up.
