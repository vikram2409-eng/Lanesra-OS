Early Access Windows build of the Lanesra OS desktop edition, and the Team Workspace server image `ghcr.io/vikram2409-eng/lanesra-os-server:0.16.1` from the same code. The installer is not code-signed yet, so Windows warns on first run.

## What's new

**Team Workspace platform**
- A scoped REST API: every one of the eleven API scopes is enforced, including record search, bulk export and bulk write, webhook management and integration administration.
- Outbound webhooks that actually deliver `record.*`, `field.changed` and `workflow.*` events, signed with a secret shown once and rotatable.
- API clients can be limited to the networks they may call from.

**Agents**
- Agent Identities: unattended agent runs (schedules and webhooks) act as an identity of their own, never as a person. Administrators manage them on the Agent Identities screen.
- Model calls are retried with backoff and fail over to the next routing tier on provider errors.
- Runs end gracefully at their limits. A run that uses all its rounds or tokens is asked for a final answer and keeps it as a partial result.
- A malformed tool call is reported back to the agent to fix. Every model instruction now lives in a versioned prompt catalog.

## Upgrade note for Team Workspace

The server now refuses to call addresses on its own network from admin-configured URLs. List the internal services it may reach in `LANESRA_OUTBOUND_ALLOW`, for example `LANESRA_OUTBOUND_ALLOW=172.18.0.0/16`, then restart. See https://lanesraos.com/help/set-up-team-workspace.
