Early Access Windows build of the Lanesra OS desktop edition, and the Team Workspace server image `ghcr.io/vikram2409-eng/lanesra-os-server:0.16.2` from the same code. The installer is not code-signed yet, so Windows warns on first run.

Everything in desktop-v0.16.1, plus:

## What's new

- **Run traces.** Every pipeline and execution-graph run records a trace of its steps, model calls, tool calls and Tool-Call Firewall verdicts. Prompts and outputs are kept only if an Administrator turns that on. See https://lanesraos.com/help/run-traces.
- **Tool caps and rate limits.** Each tool an agent uses can be limited per run, disabled after failures in a row, and kept to a result size. Rate limits in the Policy Engine cap calls per tool, per connector or per workspace.
- **Budget awareness.** Each round, an agent is told how many tool-calling rounds and tokens it has left, so it can finish instead of being cut off.
- **Steps whose output is never stored.** An Agent or Transform step in an Agent Team can be marked "Don't store this step's output". The value is used in memory only and never written to checkpoints, traces or audit. See https://lanesraos.com/help/execution-graph-agent-teams.
