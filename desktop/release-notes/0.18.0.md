## What's new

- **Process Lanes, end to end.** Lanes now run in the desktop app, Team Workspace and the online demo: define a lane, walk a person through it step by step, and watch runs move. The Blueprint view is now a visual process map — stages as an ordered rail of states, each stage a column of step cards.
- **Board by stage, my steps, lane timing.** A lane's runs can now be watched on a board by stage; my steps lists the lane steps and approvals waiting on the signed-in person; lane timing reports time per stage, completion rate and rework.
- **Lane runs: notes, attachments, reassign.** Add a note or a file to a running lane at any point, and reassign a waiting step to another person; every change is audited in the run's trail.
- **Agent steps that assist.** Agent steps in a lane can now help the person at that step instead of only running on their own, and lanes work together with workflows.
- **Agent Foundry demo.** The Foundry demo is finished: build agents, watch them run, and improve them from the Optimization view.
- **Warehouse demo, rebuilt dashboard.** The warehouse dashboard now leads with the active work, the lane runner shows swim-lanes, and the mobile layout is fixed.
- **Security updates.** Dependency and advisory updates, including the cookie crate (RUSTSEC) and the lettre upgrade.

## Upgrading Team Workspace

Pull the new image and restart the container; the database upgrades itself on start. Back up the data volume and its encryption key first, as the guide describes.
