## What's new

- **Watch agent runs live.** Pipeline and Agent Team runs now report each step, model round, tool call, firewall refusal and wait for approval as it happens. An Agent Team's test run updates as each step runs. On Team Workspace, Administrators and API clients with the `events.read` scope can follow runs over Server-Sent Events at `/api/v1/runs/{id}/events`, and pick up where they left off after a dropped connection. See https://lanesraos.com/help/run-traces and https://lanesraos.com/help/api-access-and-webhooks.
- **One inbox for every approval.** Pipeline steps that need approval, Agent Team approval gates, tool calls the Policy Engine holds and voice commands that need approval all wait in **Pending Approvals**, and deciding one resumes what was waiting. A held tool call now pauses the run; approving lets exactly that call run once. Pauses already waiting move into the inbox on upgrade. Agent Team runs started from a browser on Team Workspace work again. See https://lanesraos.com/help/agent-versioning-and-approvals.
- **Security update.** The SSH library behind SFTP connections was upgraded for advisory RUSTSEC-2026-0387. A pinned SFTP host key still names exactly one key.

## Upgrading Team Workspace

Pull the new image and restart the container; the database upgrades itself on start (one new table and three new columns, nothing removed; pauses already waiting move into the approvals inbox). Back up the data volume and its encryption key first, as the guide describes.
