## What's new

- **Watch agent runs live.** Pipeline and Agent Team runs now report each step, model round, tool call, firewall refusal and wait for approval as it happens. An Agent Team's test run updates as each step runs. On Team Workspace, Administrators and API clients with the `events.read` scope can follow runs over Server-Sent Events at `/api/v1/runs/{id}/events`, and pick up where they left off after a dropped connection. See https://lanesraos.com/help/run-traces and https://lanesraos.com/help/api-access-and-webhooks.
- **Security update.** The SSH library behind SFTP connections was upgraded for advisory RUSTSEC-2026-0387. A pinned SFTP host key still names exactly one key.

## Upgrading Team Workspace

Pull the new image and restart the container; the database upgrades itself on start (one new table, nothing removed). Back up the data volume and its encryption key first, as the guide describes.
