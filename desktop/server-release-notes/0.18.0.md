Early Access release of the **Lanesra OS Team Workspace Server** on its own version line, separate from the desktop app (ADR-0019).

## Get it

    docker pull ghcr.io/vikram2409-eng/lanesra-os-server:0.18.0

`:latest` now points at this release. Setup and upgrade guide: https://lanesraos.com/help/set-up-team-workspace

## What's in it

Everything the Team Workspace server carried through `0.17.0`, plus:

- **Process Lanes, end to end.** Lane definitions, the lane runner, the visual Blueprint process map, board by stage, my steps and lane timing, lane run notes, attachments and reassignment, and agent steps that assist the person at a step.
- **Agent Foundry demo finish** and the warehouse demo dashboard rebuild (swim-lane runner, mobile fixes).
- **Security updates.** Dependency and advisory updates, including the cookie crate (RUSTSEC) and the lettre upgrade.

## Upgrading

Pull the new image and restart the container; the database upgrades itself on start. Back up the data volume and its encryption key first, as the guide describes.

Full notes: https://lanesraos.com/releases
