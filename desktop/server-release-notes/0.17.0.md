First release of the **Lanesra OS Team Workspace Server** on its own version line, separate from the desktop app (ADR-0019). The desktop installer keeps its own `desktop-vX.Y.Z` releases.

The version jumps to **0.17.0** so the numbers never go backwards for anyone who already pulled a `0.16.x` image. The Docker image keeps its name, `ghcr.io/vikram2409-eng/lanesra-os-server`, so existing pulls and `docker-compose.yml` files keep working.

## Get it

    docker pull ghcr.io/vikram2409-eng/lanesra-os-server:0.17.0

`:latest` now points at this release. Setup and upgrade guide: https://lanesraos.com/help/set-up-team-workspace

## What's in it

Everything the Team Workspace server carried through the shared `0.16.3` release, plus:

- **One inbox for every approval.** Pipeline steps that need approval, Agent Team approval gates, tool calls the Policy Engine holds and voice commands that need approval all wait in **Pending Approvals**, and deciding one resumes what was waiting. A held tool call pauses the run; approving lets exactly that call run once. See https://lanesraos.com/help/agent-versioning-and-approvals.
- **Watch agent runs live.** Administrators and API clients with the `events.read` scope can follow a run over Server-Sent Events at `/api/v1/runs/{id}/events`, and pick up where they left off after a dropped connection.
- Run traces, per-tool caps and rate limits, budget awareness in agent turns, and steps whose output is never stored.

## Upgrading

Pull the new image and restart the container; the database upgrades itself on start (nothing is removed, and pauses already waiting move into the approvals inbox). Back up the data volume and its encryption key first, as the guide describes.
